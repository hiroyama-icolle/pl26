Codex CLI
導入・初期設定手順書

Codex CLIは、ターミナルからAIエージェントを利用するためのツールです。自然な言葉で指示すると、ファイルの読み書きやプログラムの実行などを支援します。

この手順書では、仮想環境にCodex CLIを導入し、アカウント認証やファイル操作の設定を行ったあと、小さなCLIアプリの開発まで体験します。CodexはホストOS上やVS Codeなどでも利用できます。

本手順書は作成時点の情報に基づいています。Codex CLIやUbuntuの更新により、画面表示やコマンドが変わる場合があります。

更新日：2026年11月2日

この演習について：今回は練習用の仮想環境で作業します。既存の環境を利用し、新しい仮想環境は原則として作成しません。

01

前提環境

仮想環境Vagrant
OSUbuntu
使用するBox既存環境を確認して、良さそうなものを選びましょう。今回は新しい仮想環境は作りません。
ユーザーvagrant
認証方式ChatGPTアカウント
作業ディレクトリ/home/vagrant/jugyo/codexrensyu

使えるBoxが見つからない場合は、新しく作成しましょう。その場合は仮想マシン構築の解説（4. 仮想マシン構築）を参考にしてください。

仮想環境に入り、作業ディレクトリ(~/jugyo/codexrensyu)を作成しておきましょう。

02

Codex CLIのインストール

ターミナルでインストールコマンドを実行します。

curl -fsSL https://chatgpt.com/codex/install.sh | sh

PATHを設定する

~/.bashrcを開き、ファイルの末尾に次の設定があるか確認します。なければ追記して保存してください。

vim ~/.bashrc
export PATH="$HOME/.local/bin:$PATH"

設定を反映して、Codex CLIのバージョンを確認します。

source ~/.bashrc
codex --version

バージョン情報（例：codex-cli 0.162.1）が表示されれば、インストールされています。

03

ChatGPTアカウントの認証

作業ディレクトリに移動し、Codex CLIを起動します。

cd /home/vagrant/jugyo/codexrensyu
codex
  1. 認証方法から Sign in with Device Code を選び、Enterキーを押します。
  2. 表示されたURLをコピーし、ブラウザで開きます。
  3. ChatGPTアカウントを確認して、アクセスを許可します。
  4. ターミナルに表示されたデバイスコードを入力します。
  5. ターミナルに戻り、Enterキーを押します。
  6. チャット画面で「こんにちは」と入力し、応答を確認します。

Codex CLIを終了するときは、チャット入力欄で次を入力します。

/exit
04

ファイル操作のための設定

Codex CLIにファイル操作をしてもらえるよう、仮想環境のサンドボックスに必要な設定を行います。以下の操作はCodexを終了したターミナルで実行してください。

必要なパッケージをインストール

sudo apt update
sudo apt install -y bubblewrap apparmor-profiles apparmor-utils

AppArmorプロファイルを有効化

sudo install -m 0644 \
  /usr/share/apparmor/extra-profiles/bwrap-userns-restrict \
  /etc/apparmor.d/bwrap-userns-restrict

sudo apparmor_parser -r /etc/apparmor.d/bwrap-userns-restrict

Bubblewrapの動作確認

/usr/bin/bwrap \
  --ro-bind / / \
  --proc /proc \
  --dev /dev \
  /bin/true

echo "exit code: $?"

実行結果に exit code: 0 と表示されたらOKです。

Codexのサンドボックスを確認

codex sandbox -- /bin/pwd

現在のディレクトリが表示されたらOKです。

05

Codexでファイルを操作する

codexコマンドでCodex CLIを起動し、次の指示を入力してみましょう。

"Hello World"と記述したhello.txtを作成してください

ファイルが作成されたか確認します。確認方法は自由です。

演習

ほかにも、いくつかファイルの作成やプログラムの実行を試してみましょう。

06

AGENTS.mdを作成する

AGENTS.mdは、Codexエージェントに「このプロジェクトでは、どんなルールで作業してほしいか」を伝える説明書です。人間の開発者が読む開発ルールや作業ガイドを、Codexにも用意するイメージです。

最初からすべて書く必要はありません。プロジェクトに合ったルールを少しずつ整えていけば十分です。

まずは、Codexに次の指示を入力してファイルを作ってもらいましょう。

「アシスタントは日本語を主体として応答してください。」を記入したAGENTS.mdを作成してください

作成後、catコマンドなどで内容を確認します。

演習

エージェントに事前に伝えておきたいルールを追加してみましょう。どんな内容にするか迷ったら、エージェントや周りの人と相談してみてください。

07

Git関連の設定

今回は、できるだけエージェントに作業を任せてみましょう。

ブラウザ操作などエージェントだけでは難しい作業は、自分で行うか、周りの人のサポートを活用しましょう。

08

アプリを開発する

演習として、Ubuntuで使える小さなCLIツールを作ってみましょう。Codex CLIに次のプロンプトを入力します。

Ubuntuで動作する、システム情報チェッカーをBashで作成してください。

以下の情報を取得し、日本語で見やすくターミナルに表示してください。

- コンピューター名
- OSの名称とバージョン
- CPUのコア数
- メモリの総容量と使用量
- ディスクの総容量と使用量
- システムの稼働時間

作成するファイルは `system-check.sh` としてください。

初心者にも読みやすいシンプルなコードにし、処理内容には日本語のコメントを付けてください。

また、実行方法と使用したLinuxコマンドについて説明した `system-check.md` も作成してください。
09

まとめ

Codex CLIを使った実装から、AIエージェントのサポートによるアプリの開発・実行まで体験できました。

チャット型生成AIと比べて、AIエージェントはファイルの作成やプログラムの実装、実行、修正までを一連の作業として進められることが大きな特徴です。

最後の演習

今回学んだことを活用して、自分が実際に使ってみたいオリジナルアプリをCodex CLIで作成してみましょう。
